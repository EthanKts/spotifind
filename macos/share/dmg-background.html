Install Spotifind
Three steps, about a minute.
Stuck? Open this
1
Drag to Applications
Drag the Spotifind icon onto the Applications folder above.
2
Allow it once
Open Spotifind. macOS blocks it the first time: click Done, then go to System Settings → Privacy & Security and click Open Anyway.
3
Open it again
Spotifind opens and guides you through the rest: logging in with Spotify takes one click.
